# Algebra

## Variables and Expressions
A variable is a symbol (usually a letter) that represents an unknown or changeable quantity. An algebraic expression combines variables, numbers, and operations (like +, −, ×, ÷).

Example: 3x + 5 is an expression where x is the variable, 3 is the coefficient of x, and 5 is a constant.

## Equations
An equation states that two expressions are equal. Solving an equation means finding the value(s) of the variable that make the equation true.

Example: 2x + 3 = 11. Subtract 3 from both sides: 2x = 8. Divide by 2: x = 4.

## Linear Equations
A linear equation in one variable has the form ax + b = c, where a ≠ 0. The solution is x = (c − b) / a.

In two variables: ax + by = c represents a straight line in the coordinate plane. The slope is −a/b and the y-intercept is c/b.

## Quadratic Equations
A quadratic equation has the form ax² + bx + c = 0 where a ≠ 0. Solutions are found using:
- Factoring: if ax² + bx + c = a(x − r₁)(x − r₂), then x = r₁ or x = r₂
- Quadratic formula: x = (−b ± √(b² − 4ac)) / (2a)
- The discriminant b² − 4ac determines the number of real solutions: positive → 2, zero → 1, negative → 0

## Systems of Equations
Two or more equations solved simultaneously. Methods:
- Substitution: solve one equation for a variable, substitute into the other
- Elimination: add/subtract equations to eliminate a variable
- A system of two linear equations can have one solution (intersecting lines), no solution (parallel lines), or infinitely many solutions (same line)

## Inequalities
Similar to equations but use <, >, ≤, ≥ instead of =. Key rule: multiplying or dividing both sides by a negative number reverses the inequality sign.

Example: −2x > 6 → x < −3 (sign flips).
